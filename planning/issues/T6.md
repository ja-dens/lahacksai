## Outcome

Measure whether bounded chat context and declared personalization improve sticker interpretation/comprehension, while evaluating ambiguity and confidently wrong outputs separately.

## Owner and files

Owner role B; preserve current GitHub assignees. Held-out evaluation examples, saved context-window references, measured results and intended-user comprehension notes.

## Actionables

- [ ] Use synthetic or explicitly permitted examples held apart from prompt tuning; record the source and strength of any intent label, preferably explicit sender confirmation.
- [ ] Compare matched image-only and image-plus-chat cases using the same model/criteria. Separately add relationship context and presentation preferences so their effects are distinguishable.
- [ ] Compare 20 versus 25 preceding messages using frozen windows, including long gaps, unrelated recent topics, long-text truncation, prior unsupported media and identical images with different meanings.
- [ ] Test the strongest compatible pair, sincere-versus-sarcastic opposing pairs, no defensible ranking, unreadable media and attempts to force a weaker third meaning.
- [ ] Verify that language/length preferences preserve inferred meaning and uncertainty; relationship labels must not become personality stereotypes.
- [ ] Keep voluntary validations as exchange-specific evaluation records. Never use a held-out target's own feedback as input or automatically turn stored validation into live memory.
- [ ] If exploring selective historical-example reuse offline, evaluate it separately and do not enable it in the MVP without a later decision supported by evidence.
- [ ] Ask intended users about explanation comprehension where feasible. Record sample size, wrong confident answers, compatibility/ranking errors, unsupported behavior, latency, model/token cost and limitations.

## Acceptance evidence

- [ ] Results distinguish software-policy tests, measured model performance and user comprehension.
- [ ] Matched comparisons report failures and label uncertainty, rather than claiming an optimal context length from intuition.
- [ ] The demo can show a context-dependent success and an honest uncertain case supported by observed examples.

## Handoff

The local 21-test suite verifies pipeline and output-policy behavior with substitutes; it is not an accuracy score. Do not invent confidence percentages, clinical outcomes, sender intent, sample sizes or latency improvements.
