## Current methodology

- Explain every incoming sticker automatically in an enabled conversation; no separate per-sticker AI request or mandatory validation.
- Use one backend and one multimodal call per sticker/recipient for the initial flow.
- Keep longer conversation history and a separate immutable request snapshot per sticker and recipient. Select only the preceding 20–25 messages, default 25, with no age cutoff or subsequent replies.
- Separate recipient language/length preferences, the recipient's declared relationship to this sender, and situation-specific feedback. Feedback is stored for evaluation only in the first version.
- Show the strongest two meanings only when compatible. For a rankable opposing pair, show only the best-supported meaning with an uncertainty caveat. Do not manufacture a weaker third interpretation.
