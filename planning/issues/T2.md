## Outcome

Build a transport adapter that normalizes Photon events and sends private delivery requests through injected provider clients. Finish and test it independently using a fake provider; live verification belongs to T5.

## Ownership and boundary

Role A; preserve actual assignees. Own src/adapters/photon.py, tests/test_photon.py and docs/PHOTON_ADAPTER.md. Do not edit context storage, model policy, the coordinator or another owner's files.

Inputs: provider event samples (synthetic until T1 supplies actual payloads), an injected provider client, and the shared private-delivery fixture. Outputs: v2 IncomingMessage records, private-send acknowledgment/error records, and sanitized mapping notes. Expose receive/normalize and private-send functions through documented signatures. Fake the coordinator callback, enrollment/destination resolver and provider receive/media/send operations; no database or LLM is required.

## Actionables

- [ ] Normalize stable source IDs, sender, timezone-aware timestamps, direction, kind, accompanying text, reply metadata and media. Label provisional vendor fields until verified.
- [ ] Validate event authentication through an injected verifier; reject unauthenticated events and keep secrets out of logs.
- [ ] Distinguish actual stickers from photos; decode allowed static media and enforce size/format bounds.
- [ ] Forward text as history-only input and stickers as automatic triggers; ignore assistant-originated echo events.
- [ ] Send only to the supplied application-authorized private destination, never to a source group or model-selected recipient.
- [ ] Return acknowledgment/error status honestly; API acceptance is not proof of phone receipt. Honor stable idempotency keys where the provider supports them.
- [ ] Test timeouts, unavailable media, malformed events, duplicate event IDs and two distinct messages reusing one image. Leave persistent deduplication and retry coordination to T4/T5.

## Standalone done criteria

- [ ] Supply and run `python -m unittest discover -s tests -p 'test_photon.py'` using fake clients and synthetic fixtures, without credentials, model calls or a running context module.
- [ ] Show incoming and private-send JSON matching the shared boundaries; document provisional fields and supported failure behavior.

## Handoff

T1 later replaces assumptions with verified beta payloads. T5 wires real credentials/provider clients, the coordinator and outbox and records real phone results. A mocked adapter can be complete while live Photon access remains blocked; do not call mocked results a verified integration.
