## Outcome

Demonstrate an automatic live path from an actual incoming sticker to a private explanation on the enrolled recipient's phone.

## Owner and files

Owner role C; preserve current GitHub assignees. Integration wiring, private outbox transport, configuration and sanitized live evidence.

## Actionables

- [ ] Connect the first usable A/B/C v2 boundaries after Photon access and model access are verified.
- [ ] Receive a sticker without asking the recipient to copy a chat, open an AI app, request an explanation, or validate a prior answer.
- [ ] Verify the selected target-anchored 20–25-message snapshot, no age cutoff, declared recipient settings/relationship, and app-controlled private destination.
- [ ] Confirm the model receives the actual image and bounded context, not the full stored archive or saved validation memory.
- [ ] Verify compatible-pair output and the single-best-with-caveat opposing-pair path with real outputs. Keep final unsupported/error wording distinct from a fabricated interpretation.
- [ ] Measure arrival-to-model and arrival-to-phone latency; queued local output or API acceptance alone is insufficient evidence of phone delivery.
- [ ] Exercise paused access, a source-event retry, two distinct sends of the same image, a long time gap, and an unreadable/unsupported sticker.
- [ ] Check that voluntary later feedback saves against its original context window and does not block or personalize subsequent live calls in this version.

## Acceptance evidence

- [ ] An actual sticker becomes a model-generated explanation on the enrolled phone.
- [ ] Source window, actual channel/format, private destination, latency and limitations are documented without private chat dumps.
- [ ] The team can repeat the flow and distinguish fixed demo, live inference, queued outbox, provider acknowledgment and actual phone receipt.

## Handoff

This live milestone remains open. The earlier local demo, 21 backend tests and mock SDK success are useful foundations, not a completed live integration.
