# Reusable work requests

## Refresh this plan

Read AGENTS.md, README.md, PLANS.md, docs/CONTRACTS.md, and planning/backlog.json. Inspect the current repository and the existing generated GitHub issues. Update the roadmap and issue definitions to reflect the product decisions in this chat. Keep independent ownership, clear input/output boundaries, dependencies, and observable acceptance criteria. Preserve unrelated files and human issue notes. Run planning checks and publish within the repository and scope already authorized in this conversation. Report actual file, issue, and PR links; distinguish completed work from assumptions.

## Implement one task

Read AGENTS.md, PLANS.md, docs/CONTRACTS.md, and the selected task definition under planning/issues/. Inspect the relevant files and implement that task on a feature branch. Use sample inputs or substitute components for unfinished dependencies. Run relevant checks, record evidence and limitations, update the plan, and prepare the change for review. Do not mark the task complete without its acceptance evidence.

## Verify and hand off

Inspect the selected task's acceptance criteria and current diff. Run the meaningful available checks, identify integration assumptions, and document how the next owner can reproduce the result. Record changed interfaces and unresolved failures. Report a concrete handoff with input/output examples and observed results.
